# Indian-Home-Test-Batting-Analysis
Data science project analyzing the decline in India’s home Test batting performance (2015–2025) using Machine Learning

This project investigates factors affecting India's batting performance
in home Test matches such as pitch conditions, innings, and match context.

## Tools Used
- Python
- Pandas
- Scikit-learn
- Matplotlib

## Machine Learning Model
Random Forest Regression was used to analyze factors influencing runs scored.
